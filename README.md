# Precedent

An incident response agent built on top of Hindsight memory, providing context-aware triage, automated hypothesis generation, and memory-driven incident analysis.

## Setup Steps

1. Clone the repository and copy `.env.example` to `.env`.
2. Start infrastructure: `docker-compose up -d`
3. Load seed dataset: `make seed`
4. Run backend tests: `make test`
